Hush

Hush is an Android notification blocker for people who want fewer interruptions.

It holds notifications back and can release them together as one digest. The digest schedule can be off, every hour, every 3, 6, or 12 hours, or daily at 8 AM. Clock lock holds the phone clock on one chosen time zone, Las Vegas by default, so the network cannot move it. A build workflow produces the installable APK.

Latest change. 2026-11-16, v2026.11.16. Added Clock lock. Hush holds the phone clock on a chosen time zone, Las Vegas by default. When anything turns automatic time zone back on, Hush turns it off again right away, and if the clock still lands on the wrong zone Hush posts an alert that opens the date and time screen. Flipping that setting off for you needs a one time permission granted over wireless debugging.
