Hush

Hush is an Android notification blocker for people who want fewer interruptions.

It holds notifications back and can release them together as one digest. The digest schedule can be off, every hour, every 3, 6, or 12 hours, or daily at 8 AM. A build workflow produces the installable APK.

Latest change. 2026-11-04, v2026.11.04. Created Hush, an Android app that blocks notifications.
