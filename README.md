Hush

Hush is an Android notification blocker for people who want fewer interruptions.

It holds notifications back and can release them together as one digest. The digest schedule can be off, every hour, every 3, 6, or 12 hours, or daily at 8 AM. Clock lock holds the phone clock on one chosen time zone, Las Vegas by default, so the network cannot move it. A build workflow produces the installable APK.

Latest change. 2026-11-19, v2026.11.19b. Rebuilt the Hush screen so every state reads at a glance. A banner at the top says whether Hush is blocking and how many apps. Every setting shows a fixed size ON or OFF badge instead of a switch. Every app row shows BLOCKED in red or ALLOWED in green, and blocked rows are tinted red. The clock line shows in green when the clock is correct and in red when it is wrong. Nothing on the screen changes size or moves when a state changes.
