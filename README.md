Hush

Hush is an Android notification blocker for people who want fewer interruptions.

It holds notifications back and can release them together as one digest. The digest schedule can be off, every hour, every 3, 6, or 12 hours, or daily at 8 AM. Clock lock holds the phone clock on one chosen time zone, Las Vegas by default, so the network cannot move it. A build workflow produces the installable APK.

Latest change. 2026-11-23, v2026.11.23. Blocked notifications that refuse a plain cancel are now snoozed instead.
